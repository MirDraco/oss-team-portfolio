# 병합 충돌 해결 실습

실제 배포와 분리한 로컬 연습 브랜치에서 재현한 사례입니다.

- **발생 상황:** `dev`의 같은 커밋(`4b01d83`)에서 `practice/index-intro`와 `practice/index-review`를 나눴습니다. 두 브랜치가 `index.html`의 메인 소개 문단 한 줄을 각각 팀원별 페이지 제작과 코드 리뷰를 강조하는 문구로 바꿨습니다. `practice/index-review`를 `practice/index-intro`에 병합하자 Git이 `index.html`을 `UU`(양쪽에서 수정)로 표시했습니다.
- **해결 방법:** 어느 한쪽 문구만 선택하지 않고, 두 변경의 의도가 남도록 한 문장으로 합쳤습니다. 충돌 표시를 제거하고 병합 커밋 `a926193`을 만들었습니다.
- **결과:** 미해결 파일 없이 병합을 완료했습니다. 브라우저에서 합친 문장이 한 번만 표시되고 ‘프로젝트 보기’와 ‘팀원 만나기’ 버튼이 각각 `gallery.html`, `members.html`을 여는 것을 확인했습니다. `main`과 `dev`에는 반영하지 않았습니다.

> 각자의 관심사를 살려 맡은 페이지를 만들고, 코드 리뷰를 거쳐 하나의 웹사이트로 연결합니다.
